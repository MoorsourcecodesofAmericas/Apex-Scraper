# CONTEXT.md — Apex Scraper Background

## Project Origin

Created on 2026-07-14 by Devonte Pendergrass (@StackNSatoshi). The goal was to build the ultimate web scraper agent native to OpenClaw that is undefeated, accurate, precise, relentless, and capable of critical thinking.

## Available Arsenal

| Capability | Purpose |
|------------|---------|
| web_fetch | Basic content extraction (fastest, no JS) |
| Scrapling CLI | Anti-bot HTTP + browser scraping with camouflage |
| Scrapling Python | Full control: StealthyFetcher, spiders, async sessions |
| Firecrawl API | Clean markdown extraction with anti-bot |
| Playwright | Full browser automation (last resort) |
| nodriver | 🥇 Stealth champion — drives Chrome over direct CDP |
| Camoufox | Firefox-based fingerprint spoofing |
| SeleniumBase UC | Auto-Cloudflare-Turnstile solving |
| Crawl4AI | LLM-optimized Markdown extraction |
| curl_cffi | Undetectable HTTP-only TLS fingerprinting |

## Red Team Intelligence (July 2026)

nodriver is the undisputed anti-detect champion (28/31 targets OK, 0 blocked in benchmark). It removes Playwright from the control plane entirely, making automation-protocol fingerprinting impossible. Camoufox and Patchright are secondary options.

## Key Anti-Bot Systems

- Cloudflare Turnstile — Used by ~40% of the web
- DataDome — E-commerce/finance (only nodriver passes)
- Kasada — Real estate, travel (TLS + HTTP2 + fingerprinting)
- PerimeterX — Retail (human-like patterns + proxies)
- Akamai — Enterprise banking (consistency + real behavior)
